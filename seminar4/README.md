# Семинар 4. Защита полномочий, цифровой двойник и ревизор

## Домашнее задание

**[Формулировка ДЗ: Финальный Полигон 4](ДЗ.md).**

Домашнее задание выполняется в отдельном файле [`polygon4/agent.py`](../polygon4/agent.py)
и сдаётся в финальный тур `c9` на стенде. [Подробное описание пакета и команд](../polygon4/README.md)
находится в папке `polygon4/`.

## Материалы аудиторного занятия

На занятии разбираются четыре защитных и аналитических механизма в файле
[`seminar4/practice_agent.py`](practice_agent.py):

1. Кодовый префильтр хозяйственной рассылки и дубликатов до вызова языковой модели.
2. Шлюз полномочий `sanitize_claims`, блокирующий косвенные инъекции (`directive_trap`)
   и неподтверждённые слухи конкурента.
3. Оценка вероятности реального сбоя поставщика по открытому досье прошлых поставок.
4. Расчёт матрицы гипотез и цены совершенной информации `EVPI` в библиотеке
   `WhatIfSandbox` для выбора момента обращения к ревизору (`audit_requests`).

Запуск интерактивной диспетчерской из корня `seminars/`:

```bash
python -m polygon4 studio
```

Запуск проверок занятия из корня `seminars/`:

```bash
python seminar4/test_practice.py -v
python -m polygon4 check --agent seminar4/practice_agent.py --mode scripted
```
