# Запись локального запуска

Готовый помощник `record_run.py` сохраняет команды и компактные результаты
локального запуска кодингового агента. Это инструмент к разобранному решению,
не домашнее задание. Вычислительные заготовки и задания с TODO убраны из раздачи.

Помощник не отправляет решение на стенд и не перезаписывает существующий JSON.
В файл не включаются токены, промпты, содержимое файлов и тексты ошибок.
Описание аргументов доступно из корня `seminars/`:

```bash
python polygon2/evaluation/record_run.py --help
```

Рядом находится `test_record_run.py` с автономными проверками помощника.
Основное решение занятия остаётся в `polygon2/agent.py`.
