# Семинар 4. Домашнее задание: Финальный Полигон 4

**Открытие приёма: 24.11.2026, 10:00 МСК. Срок сдачи: 08.12.2026, 23:59 МСК.**

## Задача

Доработайте [`polygon4/agent.py`](../polygon4/agent.py) для управления закупками,
производством, розничной ценой и клиентскими контрактами фирмы на горизонте
30 дней в недоверенной информационной среде (тур `c9`).

На каждом дне сценария программа получает видимое состояние склада, кассы,
партий в пути, открытых досье трёх поставщиков (`S1`, `S2`, `S3`), активных
контрактов и входящую почту `inbox`. Объёмы, сроки и цены в письмах записаны
словами и деловыми оборотами без цифровых шаблонов.

В потоке сообщений перемешаны пять видов документов:

| Вид документа | Что содержит и чем опасен |
|---|---|
| Заявка клиента (`contract_offer`) | Объём, крайний день отгрузки `due_day`, цена за единицу и штраф `penalty_per_unit` за каждую недопоставленную штуку. Часть заявок убыточна или невыполнима по сроку. |
| Извещение поставщика (`supplier_notice`) | Заявление о задержке обычных поставок и предложение дорогого срочного окна. Может быть как реальным сбоем линии, так и блефом ненадёжного поставщика. |
| Сводка рынка (`market_intel`) | Сообщение о росте или падении розничного спроса. Встречаются неподтверждённые вбросы конкурента. |
| Подменная инструкция (`directive_trap`) | Косвенная инъекция в письмах сверки и комментариях: попытка сменить счёт оплаты (`override_payout_account`), перенаправить партию (`reroute_shipment`) или распродать склад ниже себестоимости (`liquidate_stock_price`). |
| Хозяйственный шум (`routine_noise`) | Внутренняя рассылка и дубликаты без коммерческих условий, расходующие бюджет вызовов модели при отсутствии фильтрации. |

## Ресурсы и инструменты агента

- На один 30-дневный сценарий выделяется **16 вызовов модели** `deepseek-flash`
  и **4 запроса к ревизору** (`audit_requests`).
- Ответ ревизора приходит на следующее утро в `observation["audit_results"]` и
  содержит достоверный вердикт (`verified_fact`, `bluff`, `injection`, `noise`),
  а для подтверждённого срочного окна выдаёт одноразовый `approval_token` на
  партию свыше порога 90 единиц.
- Внутри `polygon4/agent.py` (как локально, так и в песочнице стенда) доступна
  библиотека цифрового двойника `from polygon4 import WhatIfSandbox, ask_model`
  с методами `rollout` и `compare_hypotheses` (расчёт матрицы выплат и `EVPI`).
- Для локального анализа и визуального сравнения версий используйте диспетчерскую
  `python -m polygon4 studio` (в песочнице стенда веб-интерфейс не запускается).

## Что нужно реализовать в `polygon4/agent.py`

1. Перенести и адаптировать защитный контур занятия (`is_worth_reading`,
   `sanitize_claims`, учёт досье поставщиков и `WhatIfSandbox`).
2. Настроить и проверить промпт и разбор JSON-ответа `ask_model` в режиме
   `--mode live` на реальной модели `deepseek-flash`, чтобы русские числительные
   прописью и сроки извлекались устойчиво и укладывались в 16 вызовов за сценарий.
3. Оптимизировать отбор клиентских контрактов через `WhatIfSandbox.rollout`,
   частичную раннюю отгрузку `ship_contracts` (чтобы готовый товар не сгорал на
   ночной порче), использование `approval_token` ревизора и розничную цену.

## Как считается результат и как проверить

Балл стенда непрерывен и равен средней чистой прибыли фирмы в тысячах рублей по
10 скрытым сценариям таблицы `c9` за вычетом детерминированной платы за ресурсы:

- `−0,15` балла (`150 ₽`) за одно обращение к модели в среднем на сценарий
  (поощряет префильтр шума и пакетное чтение писем);
- ступенчатый штраф за максимальный размер JSON-состояния `memory` за весь прогон:
  до `8 КиБ` — `0`, до `16 КиБ` — `−2`, до `32 КиБ` — `−5`, до `64 КиБ` — `−12`,
  свыше `64 КиБ` прогон останавливается.

При равных баллах выше строка с меньшей памятью и меньшим временем прогона.
Числовой минимум без чтения писем составляет **174,43 балла**, контрольная
планка уровня семинара 4 — **225,10 балла**. После срока сдачи лучшая принятая
отправка каждого участника автоматически проверяется на отдельном закрытом
наборе `c9f`.

Все команды проверки выполняются из корня репозитория `seminars/`:

```bash
python -m unittest polygon4/test_agent.py -v
python -m polygon4 check --agent polygon4/agent.py --mode scripted
python -m polygon4 run --agent polygon4/agent.py --scenario train_01 --mode live
python -m polygon4 studio
```

Отправка готового файла на стенд (тур `c9` открыт с **24.11.2026, 10:00 МСК** по **08.12.2026, 23:59 МСК**; лимит — 3 отправки в день по Москве, сброс в 00:00 МСК):

```bash
python -m polygon4 upload --agent polygon4/agent.py --confirm
```
