# Семинар 3. Разобранное решение

Решение занятия находится в [polygon2/agent.py](../polygon2/agent.py).
Это продолжение кодингового агента из семинара 2. Рабочий файл сохраняется
в том виде, в котором его доработали на занятии.

[Проверки разобранных случаев](test_agent_s3.py) можно запустить из корня
репозитория `seminars/`:

```bash
python seminar3/test_agent_s3.py -v
```

Отдельного домашнего задания, списка обязательных доработок и новой сдачи
по семинару 3 нет.
